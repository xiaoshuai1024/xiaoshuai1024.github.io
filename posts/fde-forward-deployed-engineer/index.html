年薪 75 万美金的 FDE 没人科班：我拆完 1000 份 JD，说点实话

两个数字放在一起看，很有意思。

第一个来自财联社：国内招聘平台上，FDE 的招聘需求涨了 42 倍，头部大厂给到年薪上百万。第二个来自数据团队 Bloomberry 2026 年 1 月的报告：他们拆了 1000 多份 FDE 招聘 JD，2025 年上半年的岗位数是 2024 年同期的 12.65 倍，平均总包 173,816 美金，基础模型实验室的 FDE 平均 25 万美金一年。

FDE，Forward Deployed Engineer，前置部署工程师。顺便纠个错：财联社把它译成「前端部署工程师」，不少国内的转述文章跟着抄错了。Forward 在这里是「向前推进到前线」的 forward，跟前端没有关系。硅谷给这个岗位起了个外号：the hottest job in AI that nobody was trained for，AI 圈最火、但没人受过科班训练的岗位。

高薪、暴涨、零科班，三件事同时成立，通常说明这个岗位正在被重新定义，定义权暂时握在第一批从业者和招聘方手里，市场上的信息是混乱的。你打开招聘软件搜 FDE，会看到一半岗位在要 Python 和 Agent 开发经验，另一半在要「客户沟通」和「方案讲解」，它们看起来根本不像同一个工种。

所以这篇文章不聊概念，聊数据。我把 Bloomberry 的 1000 份 JD 拆解、Anthropic 官方招聘页的 JD 原文、Levels.fyi 和猎聘的薪资档位放在一起，回答三个问题：这个岗位到底在干什么，门槛具体卡在哪，以及什么样的开发者应该转、什么样的千万别碰。

一、说人话：带着模型住进客户公司的工程师

FDE 这个词是 Palantir 造的。2003 年这家公司成立时的核心打法，就是把自己最强的工程师派到客户现场：情报机构、金融公司的办公室里，贴着客户的真实数据和真实流程做系统。工程师从大后方（总部）被推到最前线（客户现场），forward 说的就是这个位移。

类比一下：资深的家电维修老师傅，一部分坐店等机器送上门，另一部分直接背着工具箱去客户家里，看现场的使用环境、看接线、当场改方案。FDE 就是上门的那批。模型公司在总部把模型练好，但模型在客户那里跑不起来、跑起来不好用、好用了没人敢信，这些问题没有一个能靠远程支持解决。

为什么 2025、2026 年这个岗位突然爆炸？因为 AI 公司们撞上了同一堵墙。

Anthropic 官方 FDE 招聘页的 JD 是这么写的（原文照译）：客户想知道 Claude 的模型、API 和 SDK「如何在他们真实的业务场景里发挥价值」。这句话背后是整个行业的付费逻辑变了。2023、2024 年客户买的是 API 调用额度，跑个 demo 就能立项；2025 年之后客户只肯为「跑在我环境里、接了我的数据、过了我的安全审计、我的员工真的在用」的东西付钱。

从 demo 到生产环境之间，隔着数据隔离、权限对接、内部系统集成、效果评测、故障响应，每一段都能卡掉一批公司。模型公司发现销售工程师不会写代码、远程支持团队进不了客户机房，于是把两类人杂交成一个新岗位：代码要能上生产，人要能进客户现场。需求就这么起来的。

这个岗位的真实构成，比定义更重要。Bloomberry 把 1000 份 JD 按职责拆开，发现市场上叫 FDE 的岗位其实是三种不同的工作：

第一种，真·Builder，占 60%。在客户现场用客户数据搭实际能用的应用，写 Agent、接 RAG、调模型，产出是代码和跑起来的系统。第二种，改了名的销售工程师，占 30%。主要工作是配置 demo、陪销售拜访、在售前环节回答技术问题，产出是演示和合同。第三种，内部 AI 平台工程师，占 10%，集中在银行这类机构，挂着 FDE 的 title，实际在自家内部做 AI 平台，一次客户现场都不去。

三种岗位共用一个名字，薪资和成长路径差得很远。所以投简历之前先过一道判别，我在这里给一个试金石：拿到 offer 之前直接问对方团队的日常产出是什么，或者更直接地问一句：「入职第一个月，你们是先给我配开发环境，还是先让我做 PPT？」问要开发环境的，是 Builder；问要 PPT 的，是销售支持岗换个名字。后者没有什么不好，只是两者的职业积累完全不同，你得知道自己买的是什么。

二、拆 JD：门槛卡在哪，数据说了算

「AI 岗位是不是都很玄，要求一堆论文背景？」这是我被问得最多的问题。JD 数据的回答很干脆：不是。

Bloomberry 对 1000 份 JD 做了技能词频统计，前排是这样的：Python 出现在 66% 的 JD 里，TypeScript 35%，Agent 开发 35%，通用 LLM 经验 31%，RAG 12%，LangChain 6%。没有一篇论文要求进前十。这个分布翻译成人话：FDE 要的是能快速写工程代码的人，Python 是硬通货，Agent 和 LLM 应用经验是新增项，RAG 这类具体技术反而要求不广。

真正卡人的是另外三个数字。

47% 的 JD 明确要求客户沟通技能，这不是「加分项」，是写在要求栏里的。68% 的岗位要求出差，其中相当一部分是「大部分时间在客户现场」。经验要求上，3 到 5 年的占 60%，5 到 8 年的占 25%，留给应届生和初级工程师的口子不到 15%。

这三个数字合起来画像就很清楚了：FDE 不是 entry-level 岗位，公司花钱买的是「能独立扔到客户现场还搞得定的高级工程师」。你需要在不熟悉的环境里、面对不熟悉的技术栈、和利益并不总一致的客户方 IT 团队协作，把系统跑起来。这件事的难度不在任何一项技术，在于所有麻烦同时发生。

Anthropic 的面试流程可以佐证这个判断。他们的 FDE 面试一共五轮：招聘官初筛、一轮技术、一轮 coding、带回家作业（take-home），最后是团队匹配。注意有两轮单独的技术考察，但同样有一轮专门看你和这个团队的相处，因为进了组你就是要被派出去面对客户的人。

顺带说一句 JD 里的工具要求。海外 JD 普遍写着「熟悉 Claude Code、Cursor 等编程工具的使用」，按我在实际工作里见到的使用频率排：Claude Code 用得最重，Cursor 其次，OpenCode 和 Codex 在特定场景出现。工具本身不难学，难的是 JD 真正暗示的那件事：你得习惯在没有同事帮你把关的环境里，靠自己带着 AI 工具把交付从头跑到尾。

三、薪资：溢价给的是稀缺，不是模型知识

先看海外。Bloomberry 口径的 FDE 平均总包 173,816 美金；Levels.fyi 的中位数 205,000 美金；Palantir 作为起源地，中位 215,000 美金。分层最清楚的一组数据来自对 982 个在招岗位的统计：基础模型实验室的 FDE 平均 25 万美金，其他行业的 FDE 只有 14.8 万美金。行业选择对薪资的影响比资历更大。

Anthropic 的档位表拉得最开。按招聘信息整理：L4 年薪 21 万美金 base、总包约 34 万；L5 base 30 万、总包 53 万；L6 base 30 万、总包 63 万；L7 base 33 万、总包 78.5 万。另一组口径来自 LinkedIn 上在职者的爆料：Anthropic 中级 FDE 总包 66.5 万到 75 万美金。两个口径互相咬合，中级 75 万、高级 78.5 万，这个岗位的高级档总包确实站上了七八十万美金。这是把「工程 + 客户」复合能力定价最高的地方。

再看国内。字节豆包、百度文心、阿里通义的 FDE 相关岗位，月薪普遍在 3.5 万到 7 万、15 薪制，资深档年薪过百万；猎聘上北京的 AI 解决方案服务商挂 40-60k·15 薪，标题写「前沿部署工程师」的岗位 30-40k·18 薪。比普通后端同档高出一截，但和海外直接换算后的金额还有距离，且国内岗位里「销售工程师改名」的占比明显更高，试金石那一节讲的三类分布，国内尤其要留神。

怎么理解这个溢价？我的看法：市场缺的从来不是「懂模型的人」（模型公司自己一抓一大把），也不缺「能面对客户的人」（每个销售团队都有）。缺的是两者交集中的那批人：代码能上生产，客户面前也不怵。交集小，所以贵。换句话说，FDE 的溢价是对复合稀缺性的定价，不是对模型知识的定价。你想吃这碗饭，该补的不是Transformer 论文，是「把系统在别人的环境里跑起来」的交付能力。

四、谁在转，怎么转

LinkedIn 上 100 位 FDE 的从业背景被统计过，分布是：后端和全栈工程师占 45%，销售工程师占 22%，数据工程师和数据科学家占 15%，咨询顾问占 10%，创始人和早期员工占 8%。

这个分布有一个藏着的结论：后端转 FDE 是主流，接近一半。原因不体面但真实：教一个工程师和客户打交道，比教一个销售写生产代码，容易太多了。沟通能力可以在场景里练，代码能力很难速成。所以如果你已经是写了几年后端的工程师，你离 FDE 的距离比你以为的近，缺的是三样东西。

第一样，AI 工具的实战交付经验。不是「用过」，是「用它交付过东西」：拿 Claude Code 把一个真实需求从零做到能跑，中间处理过它写错的时候怎么纠偏。第二样，评测能力。客户在现场问的永远不是「这模型多聪明」，是「它在我数据上到底几分」。会搭一套评测、能拿数字回答这个问题的人，在现场是稀缺资源。第三样，把技术说成人话的能力。给客户的 CTO 讲方案，五分钟讲不清架构取舍，这单就难了。

补这三样的路径不神秘：在本职工作里找一个能用 AI 工具交付的内部需求，完整做一遍，写下评测数据，再给非技术同事讲一次。这三个动作分别对应上面三样东西，成本是一个季度的业余时间。

五、丑话说在前面：什么人别转

写到这里都是好话，这一节泼冷水。

68% 的岗位要求出差，其中相当一部分是长期驻场。客户现场的节奏由客户决定：Anthropic 的 JD 里专门写了「7×24 小时随叫随到，关键任务时期要能在凌晨 2 点响应训练中断」。你的工作地点是客户的办公室，你的绩效评分有一半来自客户方的反馈，而客户方 IT 团队的利益和你不完全一致。这些是 FDE 日常的一部分，不是极端情况。

职业成长上也有一个真实的隐忧：FDE 的输入来自客户需求，AI 停下来的时候，你没有新产品输入，容易在连续的项目交付里变成高级运维。对比在总部做模型的同行，你的技术深度增长更依赖自觉。想深耕单一技术栈、对「和人打交道」消耗大于成就感、家庭状态不允许长期出差的人，这个岗位的溢价对你不成立，高薪买走的就是这些自由度。

最后拆一个数字。「42 倍」和「12.65 倍」都是真的，但都别当铁饭碗读。42 倍是国内招聘平台的需求增幅，基数极小，从几十个岗位涨到几千个，倍数好看，岗位总量和普通后端岗位比仍然少一个量级。12.65 倍是海外 2025 上半年岗位数相对 2024 同期的倍数，也是小基数上的翻番。方向是真的，AI 行业正在把预算从「训练模型」挪到「部署模型」；但速度别高估，它是一个快速放大的细分岗位，不是一个已经成熟的就业蓄水池。

六、带走三句话

把 1000 份 JD 和这些薪资数据压缩成三句能背走的话：

第一句，FDE 卖的是部署能力，不是模型知识。JD 词频里 Python 66%、论文要求零，市场用钱投票的结果很诚实。

第二句，判真假 Builder，看入职第一个月问你要开发环境还是要 PPT。60% 是真工程师岗，30% 是销售工程师改名，名字一样，人生不一样。

第三句，溢价给复合稀缺，不给单一技能。工程能力和客户能力的交集小，所以贵；两项只占一项，溢价就和普通岗位拉平了。

回到开头那个外号：没人受过科班训练的最热 AI 岗位。现在你知道这句话的完整版本了：没有人科班训练，是因为这个岗位考的两样东西，写生产代码的硬功夫和面对客户的软功夫，本来就没人能批量教，只能在实际交付里长出来。下一个被 AI 创造出来的高薪岗位，大概率还是这个配方。与其追岗位的名字，不如先把配方里的两样东西攥在手里。

文中的三张数据卡（JD 词频、薪资分层、转型来源）建议收藏备查，投简历前对着过一遍。你在招聘软件上刷到过 FDE 吗？你现在的岗位，离「工程 + 客户」这个交集还差哪一块，评论区说说。这个系列会持续更新，下一篇拆 Agent 面试题的答题结构。
