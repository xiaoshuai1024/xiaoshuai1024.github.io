DeepSeek Harness 桌面版和 CLI 装机实录：10 步装好，绕开三个真坑

装 DeepSeek Harness（DSH）失败的人，大多数不是网络问题——是包名就抄错了。npm 里 @deepseek-ai/dsh-tui 是 404，正确的包名是 harness-tui；再加上 Node 版本不达标，两道门槛拦下了大部分第一次安装的人。

这篇是全程真机实录：桌面版 6 步 + CLI 4 步装到能用，三个真坑提前绕开。

环境门槛：先过这两条

  • Node 22.19 以上，或 24 系：node -v 先看一眼，不达标先升级；
  • 包管理用 pnpm 10+：npm i -g pnpm@latest 一步到位。

版本不够也能装上，但运行期会出各种说不清的怪问题。装机问题先查环境，再查别的。

桌面版六步

第 1 步，下载：官网 www.dshdesktop.cn，macOS 和 Windows 各一个按钮。GitHub Release 直连下载慢还容易断，直接走官网。

第 2 步，安装向导：选「仅为我安装」，目标文件夹保持默认，点安装。

第 3 步，首次启动：欢迎页先选一个工作区文件夹。它会自动准备 Profile 并在后台起服务——独立窗口，不用开浏览器。

第 4 步，配 API Key：key 在 platform.deepseek.com 申请，进「设置 → 模型 → DeepSeek」粘贴。两条纪律：key 不截图、不进 Git。

第 5 步，跑第一条任务：输入框直接问，回车发送。回答流式输出，带 token 统计——能看到统计，说明请求链路全通。

第 6 步，认识界面：左侧会话列表、中间对话框、底部输入框。桌面版和网页版最大的区别是它直接读写你工作区里的文件。

CLI 四步：终端党走这条

第 7 步，一行安装：TUI 官网 dshtui.com，本机实测 21 秒装完 647 个包。注意包名是 harness-tui，抄错就是 404：

pnpm add -g harness-tui

第 8 步，启动：敲 dsh-tui 回车，首次启动自动建 Profile。全屏交互界面，头部显示当前模型和操作提示。

第 9 步，问一句验证：输入框直接问，回车发送。头部显示 deepseek-v4-flash 才算真的接上了模型。

第 10 步，记住这几条命令：

命令作用
/help命令总览
/model查看/切换模型
/session /resume会话管理与恢复
/doctor自检
dsh-tui --headless "任务"跑完即退，适合脚本调用

Enter 发送，Ctrl+O 换行。

三个真坑

坑现象解法
GitHub 直连下载慢、断、重试循环走官网 dshdesktop.cn
包名 404@deepseek-ai/dsh-tui 不存在正确包名是 harness-tui
TUI 卡死黑屏启动后无响应、黑屏Profile 损坏，重装并核对版本

三个坑我都真踩过。第三个最隐蔽——它长得像运行 bug，其实是上一次异常退出留下的 Profile 损坏。

桌面版还是终端党

我的判断：日常对话和文件任务用桌面版，脚本化和远程场景用 TUI。桌面版有完整图形界面、独立窗口，适合盯着跑任务；TUI 轻、能跑 headless，SSH 进服务器也能用，GitHub 上 1.6k star 的也是这个形态。

两个装上也不冲突，共用同一份 DeepSeek API Key。先用哪个不重要，重要的是装完跑通第一条任务——工具是拿来干的，不是拿来供的。
